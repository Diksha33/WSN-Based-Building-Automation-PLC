WSN-Based Intelligent Building Automation Using PLC

Project Overview

An intelligent building automation system integrating ESP32 wireless sensor nodes with a Siemens S7-1200 PLC through Modbus TCP communication.

 Key Features
- Real-time temperature, humidity and CO monitoring.
- Wireless sensor data acquisition using ESP32.
- PLC-based automation and control.
- Modbus TCP industrial communication.
- System simulation using Siemens TIA Portal V19.

 Technologies Used
- Siemens S7-1200 PLC
- ESP32
- TIA Portal V19
- Modbus TCP
- Sensors and Embedded Systems

 Project Objective
To develop an intelligent building automation system that combines wireless sensor networks with industrial PLC control for efficient monitoring and automation.

 Project Status
Academic Engineering Project
